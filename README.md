# Prueba desarrollador frontend React

Prueba para el cargo de desarrollador frontend con react

## Deploy on Vercel

[https://clone-01.vercel.app/](https://clone-01.vercel.app/)
https://visionary-dasik-3752a8.netlify.app/

1. Clone the repository:

```
git clone https://github.com/lmindiola89/clone-01.git
```

2. Open the project in your preferred code editor.

3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
